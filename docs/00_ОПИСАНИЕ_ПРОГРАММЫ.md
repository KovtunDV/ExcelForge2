# ExcelForge — описание программы

## Общие сведения

| | |
|---|---|
| **Наименование** | ExcelForge |
| **Класс ПО** | Настольное приложение для ETL-подобной обработки таблиц Excel |
| **Платформа** | Python 3.10+, GUI на **PySide6** (Qt 6) |
| **Лицензия / распространение** | По правилам владельца репозитория (уточняется при публикации) |
| **Язык интерфейса** | Русский |

## Назначение

ExcelForge предназначен для **автоматизации повторяющихся операций** с данными в формате Excel:

- загрузка одного или множества файлов;
- очистка и фильтрация;
- объединение таблиц (аналог ВПР, merge);
- агрегация и сортировка;
- формирование отчётов в новых файлах или в шаблонах.

Пользователь описывает процесс в виде **пайплайна** (YAML), а не в виде макросов VBA или формул на каждом листе. Это упрощает сопровождение, передачу сценария между сотрудниками и контроль версий (Git, общие папки).

## Целевая аудитория

- Аналитики и специалисты отчётности;
- Экономисты и логисты, работающие с регулярными выгрузками;
- IT-специалисты, настраивающие типовые сценарии для бизнес-пользователей.

## Функциональные возможности

### Управление сценариями

- Хранение пайплайнов в текстовых файлах YAML;
- **Builder** — визуальное редактирование списка шагов и параметров, отладочные прогоны;
- **Runner** — пакетный запуск готовых сценариев с протоколом и прогрессом;
- Встроенная документация по каждому типу шага (отдельное немодальное окно с форматированием).

### Работа с данными

- Именованные DataFrame в контексте выполнения пайплайна;
- **Глобальный контекст сеанса** — датафреймы с именем `glob_*` доступны между разными пайплайнами до закрытия приложения;
- Загрузка Excel с гибкими параметрами (лист, строка заголовка, маска файлов, служебные колонки);
- Выгрузка: простая запись, шаблон, разбиение по группам, несколько DF на листы одной книги, режимы дописывания;
- Более 15 типов шагов обработки (см. руководство пользователя).

### Интерфейс (PySide6)

| Вкладка | Назначение |
|---------|------------|
| **Runner** | Каталог YAML, список пайплайнов, запуск/отмена, блок «Информация» и «Протокол» |
| **Builder** | Редактор пайплайна, параметры шага, тестовый запуск, протокол, просмотр DF |
| **Общие настройки** | Шрифт UI, строки предпросмотра, список и очистка глобального контекста |

Дополнительно:

- Окно **просмотра DataFrame** — таблица с фильтром по подстроке и сортировкой по столбцам;
- Окно **документации шага** — HTML из Markdown, можно оставить открытым при работе в Builder;
- Выполнение тяжёлых шагов в фоновом потоке — интерфейс остаётся отзывчивым;
- Диалоги выбора файлов и каталогов при выполнении (опционально в YAML);
- Настраиваемый шрифт всего приложения, включая протокол.

### Надёжность

- Запрос повтора при блокировке выходного файла Excel;
- Предупреждения при пустой загрузке или несовпадении структуры файлов;
- Протокол выполнения с временными метками;
- Отмена выполнения пайплайна в Runner и Builder.

## Техническая архитектура (кратко)

```
app/
  main.py                 # точка входа, QApplication
  pipeline/
    runner.py             # исполнение цепочки шагов
    context.py            # RunContext, create_run_context()
    global_context.py     # сессионное хранилище glob_*
  steps/                  # реализация каждого типа шага
  ui_qt/                  # PySide6: Runner, Builder, Settings, диалоги
  docs/pipeline_steps.md  # справочник для UI
  settings.py             # JSON в %APPDATA%\ExcelForge
pipelines/                # рабочие и примеры YAML
```

Поток данных: **Excel → pandas DataFrame → цепочка шагов → Excel**.

Контексты данных:

- **Локальный** — все имена DF в `RunContext` текущего запуска; при новом запуске локальные имена не переносятся (кроме подгрузки `glob_*`).
- **Глобальный** — только имена с префиксом `glob_`; живут до закрытия приложения или очистки в «Общие настройки».

## Отличия от «просто Excel» и от Power Query

| Критерий | Excel / Power Query | ExcelForge |
|----------|---------------------|------------|
| Хранение логики | Книга / подключения | Текстовый YAML |
| Запуск без Excel | PQ — в составе Excel | Да |
| Пакетный запуск списка сценариев | Ограниченно | Runner + каталог YAML |
| Общие таблицы между сценариями | Вручную / отдельные книги | `glob_*` в сеансе приложения |
| Программируемость | M, VBA | Конфигурация шагов; расширение на Python |
| Облако | Зависит от версии Office | Локально |
