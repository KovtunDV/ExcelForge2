# ExcelForge — развёртывание и установка

## 1. Назначение документа

Инструкция для администратора или пользователя, который впервые устанавливает приложение на рабочий компьютер (Windows).

---

## 2. Системные требования

| Параметр | Минимум | Рекомендуется |
|----------|---------|---------------|
| ОС | Windows 10 (64-bit) | Windows 11 |
| RAM | 4 ГБ | 8 ГБ и более |
| Диск | 500 МБ свободно (Python + venv + данные) | SSD |
| Python | 3.10+ | 3.11 или 3.12 |
| Excel | Не обязателен для работы приложения | Для просмотра результатов |

Приложение **не требует** установленного Microsoft Excel для выполнения пайплайнов — чтение/запись `.xlsx` выполняется через **openpyxl** (библиотека pandas).

---

## 3. Получение дистрибутива

Скопируйте каталог проекта **ExcelForge** на целевой ПК, например:

```
C:\Programs\ExcelForge\
```

Структура должна включать как минимум:

```
ExcelForge/
  app/
    main.py            # точка входа (PySide6)
    ui_qt/             # Runner, Builder, настройки, диалоги
    pipeline/          # исполнитель, global_context (glob_*)
    steps/             # реализация шагов
  pipelines/           # примеры YAML (можно дополнять своими)
  requirements.txt
  docs/
  README.md
  run-excelforge.bat   # быстрый запуск (Windows)
```

Опционально положите иконку в `app/`:

- `app/1-var.ico` или `app/1 var.ico`
- `app/1 var.png` или `app/1-var.png`

---

## 4. Установка Python

1. Скачайте установщик с [python.org](https://www.python.org/downloads/windows/).
2. При установке отметьте **«Add python.exe to PATH»**.
3. Проверьте в командной строке (cmd или PowerShell):

```powershell
python --version
```

Должна отобразиться версия 3.10 или выше.

---

## 5. Виртуальное окружение и зависимости

Откройте PowerShell в корне проекта:

```powershell
cd C:\Programs\ExcelForge

python -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### Состав зависимостей (`requirements.txt`)

| Пакет | Назначение |
|-------|------------|
| pandas | Таблицы, операции над данными |
| openpyxl | Формат `.xlsx` |
| PyYAML | Чтение/запись пайплайнов |
| markdown2 | Форматированная документация шагов в UI |
| PySide6 | Графический интерфейс (Qt) |

---

## 6. Первый запуск

С активированным виртуальным окружением:

```powershell
python -m app.main
```

Откроется окно **ExcelForge** с вкладками Runner, Builder и Общие настройки.

### Ярлык на рабочий стол (необязательно)

Создайте файл `Запуск ExcelForge.bat` в корне проекта:

```bat
@echo off
cd /d "%~dp0"
call .venv\Scripts\activate.bat
python -m app.main
```

Дважды щёлкните по `.bat` для запуска без ручной активации venv.

---

## 7. Каталоги и настройки после установки

| Что | Где |
|-----|-----|
| Пайплайны по умолчанию | `ExcelForge/pipelines/` |
| Пользовательские настройки UI | `%APPDATA%\ExcelForge\settings.json` (шрифт, строки предпросмотра, не хранит glob_*) |
| Глобальные DF `glob_*` | Только в RAM сеанса; очистка — «Общие настройки» |
| Рабочие данные | Задаются в YAML (`file_path`, `directory`, `out_dir`) |

Папку `pipelines` можно перенести на сетевой диск; путь к ней выбирается в Runner и Builder.

---

## 8. Обновление версии

1. Сохраните свои YAML из `pipelines/` и пользовательские данные.
2. Замените каталог `app/` и `requirements.txt` новой версией.
3. В venv выполните:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

4. Проверьте запуск на тестовом пайплайне.

---

## 9. Типичные проблемы

### «python не является внутренней командой»

Python не добавлен в PATH. Переустановите Python с галочкой PATH или укажите полный путь, например:

`C:\Users\Имя\AppData\Local\Programs\Python\Python312\python.exe -m app.main`

### Ошибка активации venv в PowerShell

Разрешите выполнение скриптов (один раз, от администратора):

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Файл Excel занят при сохранении

Закройте открытый в Excel файл результата. В save_excel предусмотрен диалог **Retry**, если файл заблокирован.

### Пустой список пайплайнов

Укажите каталог с файлами `*.yaml` / `*.yml` кнопкой **«Выбрать…»** на вкладке Runner.

### Нет иконки окна

Положите `1-var.ico` или `1 var.png` в каталог `app/` (см. раздел 3).

## 10. Развёртывание без исходников (опционально)

Для распространения «одним exe» можно собрать проект через **PyInstaller** (не входит в базовую поставку):

```powershell
pip install pyinstaller
pyinstaller --onefile --windowed --name ExcelForge -m app.main
```

Требуется отдельная проверка путей к `pipelines/` и `app/docs/pipeline_steps.md` в собранном бинарнике. Для корпоративного использования рекомендуется сначала пилот на интерпретируемой установке (разделы 5–6).
