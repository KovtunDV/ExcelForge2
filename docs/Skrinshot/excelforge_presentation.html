ExcelForge

программа для ETL-обработки Excel через YAML, pandas и GUI

Назначение

Что делает программа

🧩

Собирает pipeline из шагов

ExcelForge описывает загрузку, фильтрацию, объединение, преобразование и сохранение данных в YAML-пайплайне, который затем исполняется через Runner или настраивается в Builder.

📁

Работает с Excel как с источником и результатом

Программа загружает листы Excel в DataFrame pandas, выполняет обработку без VBA и может выгружать результат обратно в Excel в разных режимах записи.

Практическая польза

Почему это ценно в работе

⚡

Снижение ручного труда

Повторяющиеся операции над Excel выносятся в переиспользуемый pipeline вместо ручных действий в книге.

🔁

Повторяемость результата

Один и тот же YAML можно запускать снова и получать одинаковую логику обработки с контролируемыми параметрами.

👥

Порог входа ниже, чем у кода

Пользователь управляет шагами через GUI Builder и Runner, а не пишет полноценный Python-скрипт с нуля.

Сценарии

Где ExcelForge особенно полезен

Сверка и обогащение таблиц

Загрузка нескольких Excel-файлов, merge или map_lookup по ключам, перенос недостающих значений и формирование итоговой таблицы для бизнеса.

Подготовка отчетов

Фильтрация строк, переименование столбцов, агрегация, сортировка и выгрузка результатов в шаблонный или новый Excel-файл.

Массовая обработка типовых выгрузок

Когда структура входных файлов повторяется, pipeline превращает разрозненные Excel-операции в стандартную процедуру запуска.

Работа с несколькими DataFrame

Builder позволяет держать и комбинировать несколько DF, включая глобальный контекст для повторного использования между запусками.

Как устроено

Основной поток работы

1️⃣

Загрузка

load_excel переносит листы Excel в DataFrame.

2️⃣

Преобразование

filtration, query, df_assign, merge, groupby и другие шаги изменяют данные.

3️⃣

Проверка

В Builder можно тестово исполнять шаги и просматривать DataFrame.

4️⃣

Выгрузка

save_excel сохраняет результат в один файл, маскированный набор файлов или листы.

Архитектурно продукт объединяет GUI на PySide6/Qt, YAML-описание пайплайнов, pandas/DataFrame как ядро обработки и Excel как основной формат входа и выхода.

Функции

Операции, которые покрывает программа

Импорт и экспорт

Загрузка из Excel, запись в Excel, поддержка шаблонов, масок листов и режимов перезаписи.

Трансформации DF

Фильтрация, query, concat, drop rows, transpose, переименование и приведение типов.

Сопоставление и merge

Объединение таблиц, lookup по ключам, перенос значений и заполнение пустых ячеек.

Агрегации

groupby, суммирование, сводные операции и подготовка компактных отчетных наборов.

Параметры через GUI

fileOpenDialog, глобальные настройки и редактирование параметров шагов без ручного редактирования YAML.

Диагностика

Просмотр предпросмотра DataFrame, тестовый запуск шагов и лог выполнения для контроля результата.

Интерфейс

Что показывают экраны программы

Builder

Конструктор позволяет видеть шаги пайплайна, редактировать параметры, запускать тестовый прогон и открывать документацию по шагу.

Просмотр данных

Окно DataFrame показывает доступные DF, колонки, фильтр и фрагмент таблицы, что ускоряет проверку качества данных перед выгрузкой.

Кейс

Пример практического сценария

Сверка ВПР-таблиц без ручного Excel

  • • Загружаются две Excel-таблицы как table1 и table2.
  • • Шаг df_assign с map_lookup ищет совпадения по ключу.
  • • В целевой DF добавляются столбцы с остаточной стоимостью и новым полем.
  • • Результат сохраняется в итоговый XLSX и сразу проверяется через просмотр DF.
