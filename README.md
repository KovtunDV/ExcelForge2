# ExcelForge

GUI‑приложение (Tkinter) для создания, редактирования и выполнения **YAML‑пайплайнов** обработки таблиц Excel на базе **pandas**.

## Возможности

- **Runner** — запуск готовых сценариев из каталога `pipelines/`
- **Builder** — конструктор пайплайна, отладка шагов, просмотр DataFrame, документация по шагам
- Загрузка/выгрузка Excel, фильтрация, merge, группировка, операции с колонками и др. (см. справочник шагов)

## Быстрый старт

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.main
```
