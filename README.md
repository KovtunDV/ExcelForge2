# ExcelForge

Десктопное приложение на **PySide6 (Qt)** для создания, редактирования и выполнения **YAML-пайплайнов** обработки таблиц Excel на базе **pandas**.

## Возможности

- **Runner** — запуск готовых сценариев из каталога `pipelines/`, протокол выполнения, отмена длительных операций
- **Builder** — конструктор пайплайна, отладка по шагам, просмотр DataFrame (фильтр и сортировка), справка по шагам
- **Глобальный контекст `glob_*`** — общие датафреймы между пайплайнами в рамках сеанса работы (без повторной загрузки тяжёлых данных)
- Более 15 типов шагов: загрузка/выгрузка Excel, фильтрация, merge, группировка и др. — см. [справочник шагов](app/docs/pipeline_steps.md)

## Быстрый старт

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.main
```

Или двойной щелчок по `run-excelforge.bat` (Windows).

**Требования:** Python 3.10+, графическая среда Windows (PySide6). Отдельный пакет `python3-tk` не нужен.

## Структура проекта

```
ExcelForge/
  app/
    main.py              # запуск GUI (PySide6)
    pipeline/            # исполнитель, глобальный контекст glob_*
    steps/               # реализация шагов
    ui_qt/               # интерфейс: Runner, Builder, настройки
    docs/pipeline_steps.md # справочник для кнопки «Документация по шагу»
  pipelines/             # YAML-сценарии
  docs/                  # документация на русском
  requirements.txt
```

## Папка пайплайнов

По умолчанию — каталог `pipelines/` в корне проекта. Другой каталог можно выбрать на вкладках Runner и Builder.

## Глобальные датафреймы (кратко)

Имя DF с префиксом **`glob_`** (например `glob_raw`) сохраняется между запусками пайплайнов до закрытия программы. Подробнее — в [руководстве](docs/03_РУКОВОДСТВО_ПОЛЬЗОВАТЕЛЯ.md), раздел 3.3.
